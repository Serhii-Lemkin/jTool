[Version]
v2.8.4

[Big Changes]
- Quick Launcher Layout Menu: Added a quick configuration menu in the main launcher screen to customize app grids, greetings, hidden apps, and launcher gestures.
- Android 16 Target Compliance: Updated target API level to Android 16 (API level 36) in compliance with Google Play requirements.
- Website & Workflow Integration: Integrated project website pages and workflow definitions directly into the app and repository structure.

[Minor Changes]
- Background File Transfer Workers: Refactored file upload, download, and export services into robust WorkManager background workers (FileUploadWorker, FileDownloadWorker, FileExportWorker).
- Enhanced Date Pickers & Settings: Added improved date formatting options and preference pickers across General Settings and Calendar views.

[Bug Fixes]
- Crash Prevention & Stability: Resolved edge cases during background transfers and updated crash interceptors for improved app stability.
- UI Layout & Padding Fixes: Fixed UI spacing, margins, and gesture scrolling across launcher, vaults, and settings screens.
